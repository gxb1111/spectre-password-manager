Spectre 密码管理器

这份插件是桌面版 Spectre WebUI 的浏览器移植：算法与官方 C 实现逐字节一致 （官方测试套件 60/60 通过，另与官方 CLI 二进制对照 68/68 一致）。 主密钥只存在于内存，从不写入任何存储。

默认参数

「记住姓名」只是把姓名存进 chrome.storage.local，方便下次少打几个字。 主密钥不会以任何形式保存。

分类管理

    删除分类不会删掉收藏，里面的条目会退回「未分类」。

    收藏（0）

      导出的 JSON 只有站点名、模板、用户名、计数器、分类 —— 不含任何密码， 因为密码本来就不在插件里存着。

      导入 / 迁移

      两种格式都认：本插件的导出 JSON，以及旧版桌面 WebUI 的 spectre_data.json（{ "favorites":[{ "site","template","category","user" }] }）。

      站点名原样保留：Spectre 区分大小写，CTF 和 ctf 推出来是两套密码。 同一站点重复导入会覆盖而不是产生副本；旧版数据的 counter 一律按 1、算法按 v3 收 （旧版 server.py 调二进制时没带 -a）。

      验证

      对照官方测试向量的自检可以直接在本机跑： 

      node test/verify_vectors.js    # 与官方 CLI 二进制对照（68/68）
node test/vectors.test.js      # 官方 XML 测试套件
node test/storage.test.js      # 状态层单测

      经典自检样例：姓名 Robert Lee Mitchell、主密钥 banana colored duckling、站点 spectre.app、 v3、long → ReqoCenuXonu1?；同输入换 v0 → NejoKecuMocx6@。

      关于与隐私

      本插件不联网。没有分析、没有遥测、没有任何外部请求； 唯一的网络能力是 activeTab —— 只在你点「填入当前页」时生效。

      算法出处：com.lyndir.masterpassword（Spectre / Master Password，Maarten Billemont）。 本插件是独立实现，与上游无隶属关系。
